# INTEC - Frontend EJS

Este es el frontend del Sistema de Gestión Académica para el Instituto INTEC. Está construido con el motor de plantillas EJS y consume la API del backend para mostrar la información de manera dinámica.

## Tecnologías utilizadas
- Node.js
- Express
- EJS (Embedded JavaScript templates)
- Axios (para peticiones HTTP)
- Bootstrap 5 (para el diseño)

## Requisitos previos
- Node.js instalado
- El backend de INTEC debe estar corriendo en `http://localhost:3000`

## Instalación y ejecución
1. Clona el repositorio:
   git clone https://github.com/Jaime1145/intec-frontend-ejs.git
2. Instala las dependencias:
   npm install
3. Ejecuta el servidor:
   node index.js
4. Abre tu navegador y ve a `http://localhost:4000`.
